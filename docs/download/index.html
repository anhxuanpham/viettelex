ViệtTelex cho iPhone & iPad

Bàn phím tiếng Việt Telex/VNI với gợi ý từ, gõ vuốt, mẫu câu, clipboard.

⬇︎Tải trênApp Store
  • iOS / iPadOS 16 trở lên
  • Miễn phí
  • Chạy hoàn toàn trên máy

Sau khi cài

  1. Cài đặt → Cài đặt chung → Bàn phím → Bàn phím → Thêm bàn phím mới… → VietTelex.
  2. Khi gõ, bấm 🌐 để chuyển sang VietTelex. Thử trong app: vieejt → việt.
  3. Tuỳ chọn: bật Cho phép truy cập đầy đủ (Full Access) nếu muốn dùng rung phản hồi, âm phím riêng, nút Dán và lịch sử clipboard. Gõ tiếng Việt không cần quyền này.

ViệtTelex cho Android

Thử nghiệm

Bàn phím Telex/VNI cho điện thoại, máy tính bảng và Chromebook.

▶Sắp có trên Google Play ⬇︎ Tải APK 1.1.1
  • Android 8.0 trở lên
  • Miễn phí
  • APK ký bởi tác giả

Cài bằng APK

  1. Mở file .apk vừa tải; nếu máy hỏi, cho phép trình duyệt cài ứng dụng không rõ nguồn gốc.
  2. Mở app VietTelex → bấm Bật VietTelex (Cài đặt → Hệ thống → Ngôn ngữ & nhập liệu → Bàn phím trên màn hình), rồi Chọn VietTelex.
  3. Cảnh báo “có thể thu thập mọi văn bản bạn nhập” là cảnh báo chung của Android cho mọi bàn phím bên thứ ba — VietTelex chạy hoàn toàn trên máy.

Bản trên Google Play sẽ tự cập nhật; bản APK cập nhật bằng cách tải bản mới và cài đè. Mọi bản Android · Hướng dẫn chi tiết →

ViệtTelex cho macOS

phiên bản …

Bộ gõ chuẩn InputMethodKit: không gạch chân, gõ được trong Terminal, iTerm, Chrome.

⬇︎ Tải VietTelex.pkg
  • macOS 13 Ventura trở lên
  • Apple Silicon & Intel
  • Apple ký & notarize

Cách khác

Homebrew

brew install --cask ptrinh/viettelex/viettelex

Cập nhật bằng brew upgrade.

Một lệnh trong Terminal

curl -fsSL https://viettelex.com/install.sh | bash

Có Homebrew thì dùng Homebrew; không thì tải .pkg, kiểm chữ ký Apple rồi cài. Xem script.

Chỉ cài qua một kênh (.pkg hoặc Homebrew) — cả hai cùng quản lý ~/Library/Input Methods/VietTelex.app.

Sau khi cài

  1. System Settings → Keyboard → Input Sources → Edit… → ＋ → Vietnamese → ViệtTelex → Add (trình cài tự mở sẵn trang này).
  2. Để gõ trong Terminal/iTerm/Chrome: bật quyền Trợ năng — Privacy & Security → Accessibility → tick VietTelex.
  3. Chuyển Việt/Anh bằng 🌐 hoặc ⌃Space. Cài đặt: biểu tượng Vᴛ trên thanh menu → Cài đặt….

ViệtTelex cho Windows

phiên bản …

Bàn phím tiếng Việt của hệ thống (TSF) — chọn bằng Win+Space.

⬇︎ Tải bản x64 (.msi) ⬇︎ Tải bản ARM64 (.msi)
  • Windows 10 (1903) hoặc 11
  • Bộ cài đã ký số
  • Không cần khởi động lại

Chọn bản nào?

x64 cho máy Intel/AMD (đa số). ARM64 cho máy Snapdragon/ARM. Không chắc: Cài đặt → Hệ thống → Giới thiệu → Loại hệ thống.

Sau khi cài

  1. Chạy file .msi; cửa sổ Cài đặt của VietTelex tự mở.
  2. Chọn VietTelex bằng Win+Space. Không thấy? Mở VietTelex một lần từ menu Start.
  3. Nâng cấp: cài bản mới đè lên, hoặc bấm Kiểm tra cập nhật trong app.

ViệtTelex cho Linux

phiên bản …

Ubuntu 22.04 / 24.04 và bản dựa trên Ubuntu (amd64, arm64). Dán vào Terminal:

curl -fsSL https://viettelex.com/install.sh | bash

Lệnh thêm kho APT đã ký, cài VietTelex (Fcitx5 mặc định, hỏi nếu máy đang dùng IBus) và mở hướng dẫn bật bộ gõ. Chạy lại = cập nhật. Tuỳ chọn: | bash -s -- --ibus (giữ IBus) · --uninstall (gỡ) · --dry-run (chỉ xem các bước). Xem mã script trước khi chạy.

Fcitx5 hay IBus?

Fcitx5 (khuyên dùng, mặc định của lệnh cài): gõ mượt hơn, ít lỗi hơn trong Chrome/Electron/terminal; lần đầu cần đăng xuất/đăng nhập một lần. IBus là mặc định của Ubuntu/GNOME — chọn --ibus nếu muốn giữ nguyên.

Cách khác

Thêm kho APT thủ công 
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ptrinh.github.io/viettelex-apt/viettelex-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/viettelex.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/viettelex.sources >/dev/null <<EOF
Types: deb
URIs: https://ptrinh.github.io/viettelex-apt/
Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
Components: main
Signed-By: /etc/apt/keyrings/viettelex.gpg
EOF
sudo apt update
sudo apt install viettelex-fcitx5   # hoặc: sudo apt install viettelex-ibus

Sau đó cập nhật như mọi gói khác: sudo apt upgrade.

Tải thủ công (.deb) kèm SHA256

Chọn đúng series (~jammy1 = 22.04, ~noble1 = 24.04) và kiến trúc (amd64 = Intel/AMD, arm64 = ARM), rồi sudo apt install ./*.deb. Cách này không tự cập nhật qua apt — nút “Kiểm tra cập nhật” trong app vẫn cập nhật được.

Đang tải danh sách…

Sau khi cài

  1. Mở VietTelex trong menu ứng dụng (hoặc viettelex-settings --onboarding) và làm theo hướng dẫn.
  2. Fcitx5: đăng nhập lại một lần rồi bấm Thêm. IBus (GNOME): Cài đặt → Bàn phím → Nguồn nhập → + → Tiếng Việt → VietTelex.
  3. Chuyển Việt/Anh: Ctrl+Space.
