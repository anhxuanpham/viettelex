Tải ViệtTelex

Bộ gõ tiếng Việt miễn phí, mã nguồn mở — cài bằng một lệnh.

Ubuntu 22.04 / 24.04 (và bản dựa trên Ubuntu)

Dán vào Terminal. Lệnh thêm kho APT đã ký, cài VietTelex (Fcitx5 mặc định, hỏi nếu máy đang dùng IBus) và mở hướng dẫn bật bộ gõ. Chạy lại = cập nhật.

curl -fsSL https://viettelex.com/install.sh | bash

Tuỳ chọn: | bash -s -- --ibus (giữ IBus) · --uninstall (gỡ) · --dry-run (chỉ xem các bước).

Xem mã script trước khi chạy

Tải thủ công (.deb)

Chọn đúng series (~jammy1 = 22.04, ~noble1 = 24.04) và kiến trúc (amd64 = Intel/AMD, arm64 = ARM), rồi: sudo apt install ./*.deb. Cách này không tự cập nhật qua apt — nút “Kiểm tra cập nhật” trong app vẫn cập nhật được.

Đang tải danh sách…

macOS 14+

Dán vào Terminal. Có Homebrew thì dùng Homebrew; không thì tải .pkg bản ổn định, kiểm chữ ký Apple (Developer ID + notarize) rồi cài vào ~/Library/Input Methods.

curl -fsSL https://viettelex.com/install.sh | bash

Hoặc Homebrew

brew install --cask ptrinh/viettelex/viettelex

Hoặc tải .pkg

⬇︎ VietTelex .pkg

Sau khi cài: System Settings → Keyboard → Input Sources → Edit… → + → Vietnamese → ViệtTelex. Bật quyền Trợ năng (Accessibility) khi được hỏi.

Windows 10 / 11

Tải bộ cài .msi (đã ký) rồi nhấp đúp.

⬇︎ .msi x64 ⬇︎ .msi ARM64
