ViệtTelex for iPhone & iPad

A Telex/VNI Vietnamese keyboard with word suggestions, swipe typing, snippets and clipboard.

⬇︎Download on theApp Store
  • iOS / iPadOS 16 or later
  • Free
  • Runs entirely on device

After installing

  1. Settings → General → Keyboard → Keyboards → Add New Keyboard… → VietTelex.
  2. While typing, tap 🌐 to switch to VietTelex. Try it in the app: vieejt → việt.
  3. Optional: turn on Allow Full Access for haptics, VietTelex's own key sounds, the Paste button and clipboard history. Typing Vietnamese doesn't need it.

ViệtTelex for Android

Beta

A Telex/VNI keyboard for phones, tablets and Chromebooks.

▶Coming soon to Google Play ⬇︎ Download APK 1.1.1
  • Android 8.0 or later
  • Free
  • APK signed by the author

Installing the APK

  1. Open the downloaded .apk; if asked, allow your browser to install unknown apps.
  2. Open the VietTelex app → Enable VietTelex (Settings → System → Languages & input → On-screen keyboard), then Choose VietTelex.
  3. The “may be able to collect all the text you type” warning is Android's generic notice for every third-party keyboard — VietTelex runs entirely on your device.

The Google Play version will update itself; update the APK by installing a newer one over it. All Android releases · Full guide →

ViệtTelex for macOS

version …

A native InputMethodKit input method: no underline, works in Terminal, iTerm and Chrome.

⬇︎ Download VietTelex.pkg
  • macOS 13 Ventura or later
  • Apple Silicon & Intel
  • Signed & notarized by Apple

Other ways

Homebrew

brew install --cask ptrinh/viettelex/viettelex

Update with brew upgrade.

One Terminal command

curl -fsSL https://viettelex.com/install.sh | bash

Uses Homebrew when present; otherwise downloads the .pkg, checks Apple's signature and installs it. Read the script.

Install through one channel only (.pkg or Homebrew) — both manage ~/Library/Input Methods/VietTelex.app.

After installing

  1. System Settings → Keyboard → Input Sources → Edit… → ＋ → Vietnamese → ViệtTelex → Add (the installer opens this for you).
  2. To type in Terminal/iTerm/Chrome: grant Accessibility — Privacy & Security → Accessibility → tick VietTelex.
  3. Switch Vietnamese/English with 🌐 or ⌃Space. Settings: the Vᴛ icon in the menu bar → Settings….

ViệtTelex for Windows

version …

A system Vietnamese keyboard (TSF) — pick it with Win+Space.

⬇︎ Download x64 (.msi) ⬇︎ Download ARM64 (.msi)
  • Windows 10 (1903) or 11
  • Signed installer
  • No restart needed

Which one?

x64 for Intel/AMD PCs (most). ARM64 for Snapdragon/ARM PCs. Not sure: Settings → System → About → System type.

After installing

  1. Run the .msi; VietTelex's Settings window opens when it's done.
  2. Pick VietTelex with Win+Space. Not listed? Open VietTelex once from the Start menu.
  3. Upgrading: install the new version over the old one, or click Check for updates in the app.

ViệtTelex for Linux

version …

Ubuntu 22.04 / 24.04 and Ubuntu-based distros (amd64, arm64). Paste into a terminal:

curl -fsSL https://viettelex.com/install.sh | bash

It adds the signed APT repository, installs VietTelex (Fcitx5 by default; asks if you use IBus) and opens the setup guide. Run it again to update. Options: | bash -s -- --ibus (keep IBus) · --uninstall · --dry-run (show the steps only). Read the script before running it.

Fcitx5 or IBus?

Fcitx5 (recommended, the installer's default): smoother, fewer glitches in Chrome/Electron/terminals; the first time you need to log out and back in once. IBus is Ubuntu/GNOME's default — use --ibus to keep it.

Other ways

Add the APT repository manually 
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ptrinh.github.io/viettelex-apt/viettelex-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/viettelex.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/viettelex.sources >/dev/null <<EOF
Types: deb
URIs: https://ptrinh.github.io/viettelex-apt/
Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
Components: main
Signed-By: /etc/apt/keyrings/viettelex.gpg
EOF
sudo apt update
sudo apt install viettelex-fcitx5   # or: sudo apt install viettelex-ibus

From then on it updates like any other package: sudo apt upgrade.

Manual download (.deb) with SHA256

Pick your series (~jammy1 = 22.04, ~noble1 = 24.04) and architecture (amd64 = Intel/AMD, arm64 = ARM), then run sudo apt install ./*.deb. This route does not update through apt; the app's “Check for updates” button still updates it.

After installing

  1. Open VietTelex from the app menu (or run viettelex-settings --onboarding) and follow the guide.
  2. Fcitx5: log out and back in once, then click Add. IBus (GNOME): Settings → Keyboard → Input Sources → + → Vietnamese → VietTelex.
  3. Switch Vietnamese/English: Ctrl+Space.
